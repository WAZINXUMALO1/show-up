# SHOW UP

An events and organizer platform built with React, Vite, and Supabase.

GitHub Pages deploys the frontend from the `main` branch using the workflow in
`.github/workflows/deploy-pages.yml`. Configure the `VITE_SUPABASE_URL` and
`VITE_SUPABASE_ANON_KEY` repository Actions secrets before the first deployment.

For local setup, Supabase configuration, and the production checklist, see
[my-react-app/README.md](my-react-app/README.md).
